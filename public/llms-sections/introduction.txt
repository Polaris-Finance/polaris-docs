# Introduction

## Polaris Documentation

URL: https://docs.polaris.finance/
Markdown URL: https://docs.polaris.finance/index.md

Polaris is onchain monetary infrastructure built around pETH, a shared, yield-bearing reserve asset for permissionless currencies, commodities and synthetic assets.

Polaris minimizes trust through [immutable core mechanics](https://docs.polaris.finance/risks/security-properties), onchain collateral and bounded stewardship; assets issued by the protocol carry no blacklist or freeze function. Builders can [launch pAsset markets](https://docs.polaris.finance/architecture/passet-markets) that track any reference value available through a reliable oracle, while activity across those markets generates protocol-native yield that strengthens the shared pETH foundation.

## Polaris 101

URL: https://docs.polaris.finance/polaris-101
Markdown URL: https://docs.polaris.finance/polaris-101.md

Polaris is onchain monetary infrastructure built around pETH, **a shared, yield-bearing reserve asset** for censorship-resistant currencies, commodities and synthetic assets.

ETH enters the system through the [Polaris bonding curve](https://docs.polaris.finance/architecture/bonding-curve) and becomes pETH, the collateral asset at the center of the ecosystem. Builders can then [launch pAsset markets](https://docs.polaris.finance/architecture/passet-markets) permissionlessly against the same pETH foundation, using a reliable oracle to supply each market's reference value.

The [core protocol](https://docs.polaris.finance/risks/security-properties) operates through immutable contracts without admin privileges or asset freeze functions, while [Stewardship](https://docs.polaris.finance/architecture/stewardship) remains bounded to specified ecosystem parameters and cannot modify the bonding curve, change the liquidation mechanisms or introduce new collateral.

The flagship stablecoin of the Polaris ecosystem is USDp, which is issued against pETH collateral. It has no blacklist or freeze function and relies on protocol rules rather than a custodian for issuance and redemptions.

**Protocol yield is generated by onchain activity**, including bonding curve fees, borrowing demand, conversions and other protocol mechanisms.

Together, these mechanisms form a monetary system where protocol activity strengthens collateral, collateral supports liquidity, and liquidity drives further protocol activity without relying on offchain assets or external yield sources.

This allows value created within Polaris to remain within Polaris.

Relevant app/search vocabulary: app, official app, testnet, Sepolia, pETH, pAssets, USDp.
