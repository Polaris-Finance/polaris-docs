# Polaris Documentation

Polaris is onchain monetary infrastructure built around pETH, a shared, yield-bearing reserve asset for permissionless currencies, commodities and synthetic assets.

Polaris minimizes trust through [immutable core mechanics](/risks/security-properties), onchain collateral and bounded stewardship; assets issued by the protocol carry no blacklist or freeze function. Builders can [launch pAsset markets](/architecture/passet-markets) that track any reference value available through a reliable oracle, while activity across those markets generates protocol-native yield that strengthens the shared pETH foundation.
